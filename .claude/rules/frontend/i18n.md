# i18n 规范（长期规则）

- **文案一律走 `t("key")`**，禁止在组件里硬编码用户可见中文/英文（`no-system-dialogs.test.mjs`
  一类契约测试会卡硬编码告警文案）。
- **双语必须同步**：新增 key 必须同时加进 `src/i18n/locales/zh-CN.ts` 与 `en-US.ts`，
  键集不许漂移（`worktree-finish.test.mjs` 等以 `deepEqual(zhKeys, enKeys)` 钉住）。
- **key 归属域**：域内文案的 key 由该域自己管，`i18n/locales/*.ts` 只存文本，不放业务逻辑。
- **参数化**：用 `t("key", { time })` 传参，禁止字符串拼接组装句子（语序在别的语言会错）。
- 接线契约测试是防退化的另一半——改 i18n key 后必须同步更新对应 `web/tests/*.test.mjs`。
