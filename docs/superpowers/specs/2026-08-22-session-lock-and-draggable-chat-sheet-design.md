# 会话锁定与可拖动浮动会话面板设计

**日期：** 2026-08-22  
**状态：** 已确认，待实现计划

## 背景

当前在聊天界面选中会话后，点击同一项目内的文件、目录、Git 或任务等内容，有时会清除会话选择。右侧会话项的小圆环从已选中的灰色状态变为未选中的灰色状态；随后发送消息会意外创建新会话。

同一场景下，点击文件视图中的上箭头蓝色圆环会打开浮动会话面板。该面板目前打开后停在历史开头，且顶部看似手柄的区域点击即全屏，未提供可预期的拖拽行为。

## 目标

1. 当前项目中，已显式选择或显式新建的会话持续作为发送目标，不因浏览同项目内容而丢失。
2. 右侧会话列表持续显示锁定会话的灰色选中状态。
3. 浮动会话面板打开时显示最新消息，并允许仅通过顶部短横条真实拖拽为全屏、半屏或关闭。

## 非目标

- 不持久化会话锁定到 `localStorage`、IndexedDB 或跨刷新状态。
- 不恢复切换到目标项目之前所选的历史会话。
- 不改变点击上箭头圆环打开浮动面板的既有入口。
- 不新增第三方依赖或新的抽屉组件。

## 会话锁定模型

### 定义

当前项目维护唯一的锁定会话键。该键是发送消息、右侧列表选中态与浮动会话面板内容的单一来源；中间区域当前显示的是聊天、文件、预览、Git 或任务，与该键独立。

锁定会话可以是刚通过显式新建操作创建、尚未发送首条消息的空会话。当前后端没有创建空会话的 API，因此该空会话是仅驻留客户端的“下次发送创建新会话”意图：它不进入右侧列表，第一条消息发送成功后才由现有发送流程创建真实会话并将锁定迁移到其服务端键。

### 状态转换

| 动作 | 锁定会话 | 内容/面板 |
| --- | --- | --- |
| 在右侧列表显式选择会话 | 设为所选会话 | 沿用当前现有导航行为 |
| 通过左滑小圆环显式新建会话 | 设为新空会话 | 沿用当前现有导航行为 |
| 点击当前项目的文件、目录、Git、任务或预览 | 不变 | 切换对应内容 |
| 点击上箭头圆环 | 不变 | 打开浮动会话面板 |
| 下拖浮动面板至底部阈值 | 不变 | 仅收起浮层 |
| 切换到其他项目 | 清除原项目锁定；将目标项目置为客户端空白新会话意图 | 切换目标项目 |
| 删除当前锁定会话 | 将当前项目置为客户端空白新会话意图 | 沿用删除后的现有内容降级行为 |

只有右侧显式选会话、左滑显式新建、项目切换和删除当前锁定会话能改变锁定状态。所有同项目内容浏览都不得调用会清除该状态的路径。

### 发送和右侧列表

发送入口只读取锁定会话键。空白新会话的首条消息必须写入该会话，不能因当前中间区域为文件视图而创建另一会话。

右侧列表的灰色选中态只依据锁定会话键，即使中间区域显示文件或其他非聊天内容也不改变。

## 浮动会话面板

### 停靠状态

复用现有 `BottomSheet`，引入受控的三态停靠：

- `closed`：浮层不可见；会话锁定不受影响。
- `half`：默认半屏高度。
- `full`：将浮层当前会话提升至中间主聊天页，并关闭浮层，保留当前既有“展开”语义。

打开上箭头浮层默认进入 `half`。内容完成布局后，滚动消息容器到底部，使最新消息可见；后续消息新增时也保持底部跟随，遵循现有聊天查看器的用户主动上滚保护（若已有）。

### 拖拽

- 只有顶部短横条是拖拽入口；消息内容、输入框、操作按钮与面板其他区域均不参与拖拽。
- 使用 Pointer Events，统一支持鼠标、触摸和手写笔。
- `pointerdown` 记录起始坐标并捕获指针；`pointermove` 仅在达到最小位移后开始拖动；`pointerup` 或 `pointercancel` 计算停靠目标并释放捕获。
- 松手时按相对视口位置吸附：接近顶部（约视口高度 20% 阈值）执行 `full`，即提升至中间主聊天页；接近底部（约视口高度 20% 阈值）进入 `closed`；其他情况回到 `half`。
- 没有达到有效位移的点击不改变停靠状态，防止将手柄点击误作全屏操作。
- 关闭浮层后，上箭头圆环仍可再次打开同一锁定会话。

## 实现范围

仅修改已有的会话状态、会话选择/发送逻辑，以及 `BottomSheet` 与浮动 `SessionViewer` 的关联路径。实现前需追踪所有清除或重写当前 `selectedSession` / 项目会话选择记录的调用方，并将同项目内容导航从这些路径中剥离。

实现不应创建新的抽屉、持久化层或通用状态框架。

## 错误处理

- 锁定的会话被服务端删除、不可访问或加载失败时，统一回到客户端空白新会话意图，避免发消息时静默落入另一个历史会话。
- 浮层滚底失败不阻断面板打开；在下一次消息布局或重开时重试。
- `pointercancel` 必须回到 `half`，而非保持中间临时位置。

## 验收与测试

至少覆盖以下场景：

1. 选中会话后打开文件、目录、Git 或任务，再发送消息，消息仍进入原会话，右侧项保持选中。
2. 显式新建空会话后浏览同项目内容，首条消息仍进入该空会话。
3. 切换项目后，目标项目处于客户端空白新会话意图；首条消息创建并锁定真实会话。
4. 删除当前锁定会话后，当前项目处于客户端空白新会话意图；首条消息创建并锁定真实会话。
5. 打开浮动会话面板时最新消息可见。
6. 从短横条上拖、下拖、轻点或轻微拖动，分别得到提升至主聊天页、`closed`、`half` 的预期结果。
7. 收起浮层后，锁定会话与右侧列表选中态保持不变，并可重新打开。
