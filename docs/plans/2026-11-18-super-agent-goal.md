# Goal：Super agent R0/R1 工头闭环

- 目标：在现有 Task Router 上验证 P1，并建立受限、可审计的任务运行期协调。
- 授权：用户 2026-11-18 已接受六阶段路线图，并明确要求“文档形式、具体小任务、worktree + 任务派发去执行”。
- 本轮先执行 R0 基线核查、行为回归与真实场景验收；通过后按依赖推进 R1，不自动扩展 R2–R5。
- R0 验收：自动选择、直连、提问、显式绕过、运行中留言、失败回退均有请求、决策、执行、结果证据。
- R1 验收：Router-owned Run 的完成、失败、等待审批、停顿可持久化触发协调；每个逻辑事件最多一份可见协调结果。
- 关键边界：不自动批准 HumanGate、cancel/retry、commit/merge/删除 worktree；工程 worker 可在自己的任务分支提交。
- 可靠性：重启不得静默丢弃待处理事件；不确定的外部执行不得盲目重放。
- 并发：实现 worker 同时最多 1 个；只读 worker 最多 1 个；所有本轮命令限制 1 线程。
- 文档：共享计划、派发表、进度仅工头写；worker 只写各自 worktree 与独立报告。
- 计划：[执行计划](2026-11-18-super-agent-r0-r1.md)；[派发与证据](2026-11-18-super-agent-dispatch.md)。
